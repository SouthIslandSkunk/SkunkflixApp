Plex connection

Make sure your device has internet access and your Plex Media Server is online. For a local server, allow Local Network access for Skunkflix in iOS Settings. If automatic sign-in fails, use Manual connection with the server address and X-Plex-Token.

Chromecast

Keep your iPhone or iPad and Chromecast on networks that can reach each other and make sure Local Network permission is enabled. For device help, visit Google Cast Help.

Offline downloads

Downloads require the selected Plex Media Server to permit access to the media file. Available storage and server permissions can affect whether a download succeeds.
