# Skunkflix Support

For Skunkflix support, privacy questions, or bug reports, email [southislandskunk@gmail.com](mailto:southislandskunk@gmail.com).

## Plex connection

Make sure your device has internet access and your Plex Media Server is online. For a local server, allow Local Network access for Skunkflix in iOS Settings.

If automatic sign-in fails, use **Manual connection** with the server address and X-Plex-Token. Remote manual addresses must use HTTPS. Plain HTTP is accepted only for a local or private-network Plex server.

## Chromecast

Keep your iPhone or iPad and Chromecast on networks that can reach each other, and make sure Local Network permission is enabled.

For device help, visit [Google Cast Help](https://support.google.com/chromecast/).

Google Cast controls are available on iPhone and iPad. They are not included in the Mac Catalyst version because the bundled Google Cast SDK is iOS-only.

## Offline downloads

Downloads require the selected Plex Media Server to permit access to the media file. Available device storage, media compatibility, network connectivity, and server permissions can affect whether a download succeeds.

Downloaded files can be managed and deleted from the **Downloads** screen in Skunkflix.

## Sign out and account management

Use **Sign Out and Forget Plex** in Skunkflix to remove saved Plex tokens, account details, and server credentials from the device.

Skunkflix does not create or maintain a separate Skunkflix account. To manage or delete a Plex account, use [Plex account settings](https://app.plex.tv/desktop/#!/settings/account).

For Plex account or server-specific support, visit [Plex Support](https://support.plex.tv/).
